# Синхрон by тима осадок — experimental vocal alignment VST3
Separate project from **Ближе**. v0.1: offline tool inside a Windows Studio One VST3 interface. Drop a consolidated reference WAV as **LEAD**, then up to eight consolidated WAV backing vocals. Select **ALIGN TIMING** to run envelope-onset dynamic time warping with pitch-preserving Signalsmith Stretch. **TUNE NOTES** is a separate optional processing stage; each voiced window corrects a limited deviation from the nearest semitone interval relative to the lead (it does not intentionally force harmonies to unison). Export separate 24-bit WAV tracks, then import them into Studio One.

**Important:** this is NOT an AI phoneme-aligner and NOT ARA2. The first version uses classical onset detection and autocorrelation. DAW timeline events cannot yet be dragged straight into its UI; audio files from the OS file explorer can. Exported results are not automatically placed back into Studio One. It should be tested with real vocal recordings before production use. Large timing changes, sibilants, vibrato and singing harmonies can still cause audible artifacts. A future learned phoneme model, confidence monitoring, ARA2 host integration and better phrase-aware pitch estimation are roadmap items.

Windows x64 / JUCE 8 / C++17 / Signalsmith Stretch (MIT). Use with 44.1/48/96k WAV files exported from the same timeline zero, mono or stereo, and same sample rate. Keep backups of originals. Source is AGPL-3.0-or-later for original portions; JUCE and Signalsmith have their own licensing terms.
