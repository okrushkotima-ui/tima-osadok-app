# Синхрон by тима осадок — experimental vocal alignment VST3
Separate project from **Ближе**. v0.1: offline tool inside a Windows Studio One VST3 interface. Drop a consolidated reference WAV as **LEAD**, then up to eight consolidated WAV backing vocals. Select **ALIGN TIMING** to run envelope-onset dynamic time warping with pitch-preserving Signalsmith Stretch. **TUNE NOTES** is a separate optional processing stage; each voiced window corrects a limited deviation from the nearest semitone interval relative to the lead (it does not intentionally force harmonies to unison). Export separate 24-bit WAV tracks, then import them into Studio One.

**Important:** this is NOT an AI phoneme-aligner and NOT ARA2. The first version uses classical onset detection and autocorrelation. DAW timeline events cannot yet be dragged straight into its UI; audio files from the OS file explorer can. Exported results are not automatically placed back into Studio One. It should be tested with real vocal recordings before production use. Large timing changes, sibilants, vibrato and singing harmonies can still cause audible artifacts. A future learned phoneme model, confidence monitoring, ARA2 host integration and better phrase-aware pitch estimation are roadmap items.

Windows x64 / JUCE 8 / C++17 / Signalsmith Stretch (MIT). Use with 44.1/48/96k WAV files exported from the same timeline zero, mono or stereo, and same sample rate. Keep backups of originals. Source is AGPL-3.0-or-later for original portions; JUCE and Signalsmith have their own licensing terms.

## ARA2 proof of concept (experimental branch)
The new **FROM STUDIO ONE** lead/back controls try to access host audio through JUCE ARA 2.3. The user must first attach Synchron as an **ARA Event FX on actual audio events**, not a normal track insert. In Studio One versions where Alt changes the drop target to Event FX, drag the **plugin onto the audio event** while holding Alt; dragging an audio event into the ordinary VST3 editor is not supported by the host. Read access to linked events and rendering inside Studio One are not yet verified on a real song. The host renderer in this prototype plays back unmodified source events; processed results still require EXPORT WAV. For the moment, test only with a duplicate song, not production material.


## Studio One ARA2 BETA 0.2.1 instructions
- On a **copy** of your Studio One song, add Synchron as **Event FX** to the lead event; click **FROM STUDIO ONE** in LEAD. Audio should appear without an initial WAV bounce.
- To expose backing vocals, add **the same ARA Event FX** to each double/back audio event. Return to Synchron's editor and use **FROM STUDIO ONE** in BACKS. This only works for events made available by Studio One in the plugin's ARA document. Different host instances may not share a document, and detection across them is not guaranteed.
- Press Ctrl+F2 (Studio One's Toggle Detached Editor shortcut) to move the embedded editor to an independent window. The large empty DAW area is host window layout, not generated by Synchron. GUI itself now supports proportional resizing.
- Dragging arrangement events directly into arbitrary plugin windows via Alt is not supported by standard native Studio One audio-event drag/drop. Alt-dragging the **plugin onto the event** (in applicable Studio One versions) creates the Event FX instead.
- ARA controls read source samples, but **the aligned result is not yet written to ARA Event FX playback**. Export WAV remains required for the edited output. The current ARA audio renderer plays back the unmodified event and should not modify the original recording.
- Experiment in duplicate sessions only; the ARA model/host interface has not yet been verified with multiple backing events or across all Studio One versions.

## Drag directly back into the arrange window (0.2.1)
After ALIGN TIMING or optional TUNE NOTES, press and **drag** the bottom-right "DRAG TO STUDIO ONE / CLICK TO SAVE" control into Studio One's arrangement. The plug-in creates individual temporary 24-bit WAV files and initiates a native OS file drag. Release them on the intended arranger track at the intended position. **This is not ARA in-place rendering**, and original events are preserved. A simple click on the control still opens the Save WAV folder picker. Windows Studio One acceptance of the native drag must be checked by the user; if blocked, click to save WAV files. Temporary drag files are intentionally retained so imported clips are not broken when the plugin closes.

For **one-time ARA setup** across multiple events, select all desired lead/back events, then Alt/Option-drag the Synchron VST3 *from the Effects browser onto the selected clips*. Studio One documents adding Event FX to all selected clips in one operation. Do not Alt-drag the clips into the VST3 UI expecting them to become file drops: this is a host limitation.
