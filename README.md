# Тима Осадок Трекер — привычки, вес и маленькие победы

Прототип PWA для iPhone и Windows. Никаких зависимостей: HTML + CSS + JavaScript.

## Что работает

- Шесть ежедневных привычек: нейтрально-серые до отметки, зелёные при выполнении, отдельный вариант «Сегодня нет» с поддерживающей фразой. Можно сбросить выбор.
- Конфетти и разные шутливые поздравления за выполнение (с уважением к `prefers-reduced-motion`).
- Переключение дней, дневной прогресс, неделя без наказания за пропуски.
- Запись веса, целевого веса, калорий и график по истории измерений.
- Хранение данных на устройстве через localStorage, экспорт/импорт копии в JSON.
- Адаптивность для iPhone 15 и Windows; app manifest, офлайн-кэш (service worker).

## Запуск

Для тестирования на ПК распакуйте ZIP и откройте `index.html` в браузере. Данные сохранятся локально, но режим установки/offline PWA требует **HTTPS** или `localhost`.

Для локального сервера: `python -m http.server 8000`, затем `http://localhost:8000/`.

### Установка после публикации по HTTPS

- **iPhone:** Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Windows:** в Microsoft Edge открыть HTTPS-адрес → меню → «Приложения» → «Установить этот сайт как приложение».

**Важно:** данные на iPhone и ПК пока раздельные. Автоматической синхронизации нет. Для переноса используйте экспорт/импорт. Если браузер очищает данные сайта, записи могут пропасть без резервной копии.
