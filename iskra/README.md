# Искра · Альбом 30 дней

Статическое приложение: сборка и установка зависимостей для запуска не нужны.
Из корня репозитория запустить `python -m http.server 8000 --bind 0.0.0.0`.
Раздел альбома находится по пути `/iskra/?mode=album`.

Каждый из 30 дней содержит два вопроса с готовыми вариантами, музыкальное
действие с облегчённой версией и выбор результата. Всего 90 полей выбора
и 12 необязательных заметок (88,2% полей — готовые варианты). Обязательного
ручного ввода нет. «Вернусь позже» сохраняет ответы, но не завершает день.
Карта позволяет открывать дни в любом порядке. Повторное нажатие кнопки
завершённой миссии снимает отметку и оставляет ответы.

## Данные и совместимость

Прогресс и ответы сохраняются в прежнем ключе `iskra-album30-v1`.
Старые `day`, `done`, `mode` сохранены; добавлены `missionsVersion` и `answers`.
Прежние завершённые дни не требуют повторного прохождения новых вопросов.
Порядок вариантов в `album.js` определяет их стабильные числовые идентификаторы:
при изменении порядка или удалении вариантов потребуется миграция ответов.

`?gift=1&mode=album` использует отдельный ключ `iskra-gift-album30-v1`.
Данные треков (`iskra-studio-v1` / `iskra-gift-studio-v1`) не изменяются миссиями.
Экспорт/импорт миссий и экспорт/импорт Студии — отдельные резервные копии.
Данные локальны для браузера; синхронизация между устройствами не добавлена.
При ошибке записи показано предупреждение, а экспорт доступен для сохранения
текущих ответов. Повреждённое сохранение автоматически не перезаписывается.

## Проверки

На подготовленной облачной машине доступны Node.js, Playwright 1.62.1 и Chromium.
При работающем статическом сервере из корня репозитория:

```sh
node --check iskra/album.js
node tests/iskra-album.cjs
```

Для другой машины Playwright можно установить отдельно от приложения:

```sh
npm install --prefix /tmp/iskra-test-tools --no-save --no-package-lock playwright@1.62.1
NODE_PATH=/tmp/iskra-test-tools/node_modules CHROMIUM_PATH=/usr/bin/chromium node tests/iskra-album.cjs
```

Тесты проходят все 30 дней; проверяют миграцию, автосохранение, ограничение
множественного выбора, завершение, резервные копии, ошибки хранилища,
изоляцию подарочного режима, сохранность треков, управление клавиатурой
и ширины 320 / 390 / 430 / 1280 пикселей. Это браузерная эмуляция телефона;
проверка на физическом устройстве в неё не входит.

GitHub Pages публикует корень ветки `main` без сборки. Для изменения JS/CSS
обновлять версию соответствующего URL в `index.html`, чтобы браузер загрузил
новые ресурсы. Ключи пользовательских данных при этом не менять.
