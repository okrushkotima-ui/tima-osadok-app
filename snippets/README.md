# РИТМ · Контент

Мобильный пульт артиста в `/snippets/`. Статическое приложение без сборки, внешних ключей, регистрации и обязательных сервисов. Корневой РИТМ и соседние разделы не изменяются.

## Первый день

1. Открой раздел: появятся четыре разных задания — юмор, разговор, свой трек и студийный процесс.
2. Прочитай POV, открой сценарий. Внутри — первые слова, три кадра с таймкодами, свет, реквизит, звук, монтаж, подпись, CTA и чек-лист.
3. Копируй POV, хук, подпись, теги или полное ТЗ. «Редактировать тексты» сохраняет персональную версию только в этой карточке. Если Clipboard API недоступен, откроется выделяемый текст.
4. Отмечай «Снял», «Смонтировал», «Опубликовал». Все шесть этапов доступны в селекторе, включая «Монтаж», «Готово» и «Пропущено»; этап можно вернуть назад. Публикация отмечается после ручной загрузки на площадку.
5. «Результат»: выбери площадку, возраст и режим распространения, введи доступные показатели. Пустое поле означает отсутствие данных, а не ноль.

«Сегодня мало сил» показывает до двух простейших незавершённых карточек, не удаляя остальные. Пропуски не штрафуются. Задания можно перенести в другой день или очередь, сохранив этапы, тексты, URL и замеры. Следующий этап подсвечивается мятным.

## Идеи, замены и план

Каталог содержит **122 сценария**: 110 новых и 12 прежних, необходимых для точной миграции. Юмор — 22, разговор — 22, студия — 22, POV — 22, эксперименты — 12, свои треки — 22 (включая прежние). Десять новых музыкальных сценариев адаптированы под Тиму Осадка; также включены все пять примеров из задания. Остальной новый каталог строится на бытовых ситуациях.

Фильтры: категория, 5/15/30 минут, дом/студия/улица, лицо, музыка, конкретный реквизит, избранное/очередь. Поиск проверяет название, POV и действия. Звёздочка добавляет в избранное. «В день / очередь» создаёт карточку; повтор в той же цели блокируется.

Замены: тот же формат (категория), другая категория, проще, быстрее, без лица, POV, свой трек. Под «трендом» здесь подразумевается **вечнозелёная механика**, не случайная запись из проверенного каталога. Сначала исключаются недавние показы, уже запланированное и очередь. При исчерпании пула разрешаются наиболее давние повторы; бесконечной уникальности в ограниченном каталоге нет. История до 12 вариантов позволяет отменить замену. Отметки, чек-листы, публикации и метрики блокируют замену, чтобы не потерять работу.

Настройки: 1–8 заданий для новых дней, восемь временных слотов, разрешённые категории, трек и сохранённая старая строка. Можно применить число к выбранному дню: удаляются только полностью нетронутые карточки; если остальные уже в работе, их количество может остаться выше настройки. Время — МСК, Europe/Moscow, UTC+3; это личный ориентир, а не обещание охватов. Старые дни и время отмеченных карточек не переписываются.

План: 14/30 дней, создание пустых дней по кнопке, тема и трек дня, пакетные группы «Снять / Смонтировать / Выложить», отдельная очередь. Свободные дни отображаются без создания обязательств. Календарная кнопка открывает выбранный день.

Генератор POV/хуков — локальные шаблоны по теме и трём настроениям. ИИ и внешние запросы не используются. Проверь, что выбранная формулировка соответствует твоему опыту.

## Тренды

Редактируемый локальный каталог: механика, точный POV, пример, поисковая фраза TikTok, URL, дата проверки. Метки: «Нужно проверить», «Проверено вручную», «Вечнозелёная механика». Для ручной проверки нужны дата и URL либо поисковая фраза. Стартовые механики вечнозелёные, без выдуманной даты проверки.

Экспорт/импорт каталога: `{ "version": 1, "trends": [...] }`. У записи строковые поля `id`, `title`, `mechanic`, `pov`, `query`, `url`, `checked`, `examples` и `status`: `check`, `verified` или `evergreen`. Дата `YYYY-MM-DD`, URL только HTTP(S). Импорт заменяет каталог после проверки и подтверждения.

**Живых трендов, автоматического сбора данных и автопубликации в TikTok/Reels/Shorts/VK нет.** Для этого нужна официальная интеграция; ключи в браузер не добавляются. Музыку выбирай в разрешённом каталоге конкретной площадки или используй свой исходник. Поисковые фразы в сценариях не утверждают актуальность звука.

## Статистика

Ручные замеры на 2/24 часа и 7 дней. Для совместимости доступны 48 часов и «Возраст неизвестен». Площадки и режимы (органика, пробный Reels, реклама) сравниваются отдельно. Показатели: просмотры, лайки, комментарии, репосты, сохранения, подписки с ролика, средние секунды и процент просмотра, выбор просмотра и досмотры. Недоступное оставляй пустым. Средний процент может быть выше 100 из-за повторов, выбор/досмотр ограничены 100.

Дашборд за 7/30 дней до выбранной даты: число выпущенных роликов, история количества публикаций и медианного показателя по дням, медианы и средние по категориям/форматам/хукам, сравнение роликов. Подписчики профиля вводятся отдельно и не смешиваются с подписками с ролика. Совет о повторе категории строится на введённых цифрах; при малой выборке показано предупреждение. Это наблюдение, не доказательство влияния формата. Публикация на нескольких площадках считается одним выпущенным роликом. Замеры роликов в очереди тоже сохраняются в отчёте.

## Данные и восстановление

- Ключ новой версии: `ritm-content-v2`, `version: 2`.
- Старый ключ `ritm-snippets-v1` **никогда не изменяется**. Перед записью новой схемы создаётся `ritm-snippets-v1-backup-<timestamp>`.
- Переносятся трек, строка, время, все дни, выполненные отметки, исходные форматы и обе схемы метрик. Полная исходная структура сохраняется в `migration.legacy`, каждая исходная карточка — в `legacy`. Замеры неизвестного возраста доступны отдельно и не смешиваются с 24 часами.
- Перед импортом или сбросом сохраняется `ritm-content-v2-backup-<timestamp>`. Импорт поддерживает v2 и старый JSON; проверяются версия, даты, категории, карточки, метрики, ссылки и ID. Ошибочный файл не заменяет данные. Размер файла до 10 МБ.
- При ошибке чтения/миграции автозапись блокируется: исходник остаётся на месте. Кнопка «Исходники / бэкапы» выгружает исходные строки всех ключей РИТМ · Контент для восстановления. Это диагностическая копия; обычный импорт принимает экспорт состояния, а не оболочку raw-backups.
- При переполнении или запрете localStorage изменения остаются в памяти открытой вкладки, сверху появляется постоянное предупреждение. Скачай экспорт до закрытия. Надёжно сохранить данные без доступного хранилища приложение не может.
- Данные не синхронизируются между устройствами. Для переноса используй экспорт/импорт JSON. Очистка данных сайта удаляет и локальные бэкапы — храни скачанную копию отдельно.

## Offline и обновление

`manifest.webmanifest` и отдельный `sw.js` с областью `/snippets/`. После первого успешного открытия с сетью кэшируется оболочка. Установить можно из меню поддерживающего PWA браузера. Запросы идут в сеть при доступности, offline используется кэш. Версия оболочки и ресурсов — 4; `updateViaCache: 'none'`, `skipWaiting`, `clients.claim`. Worker удаляет только свои старые `content-shell-*` кэши. Корневой worker и кэши соседних разделов не меняются. При следующем изменении оболочки нужно повысить версии ресурсов и имя кэша.

Проверено в Chromium с viewport 390×844 и 1440×1000; доступность установки и Clipboard API зависит от браузера. Внешние источники, звуки и публикация требуют сети. Без service worker основной интерфейс работает онлайн.

## Проверки

Из корня репозитория:

```sh
node tests/snippets.cjs
node --check snippets/app.js
node --check snippets/strategy.js
node --check snippets/catalog.js
node --check snippets/sw.js
python3 -m http.server 8765
# В другом терминале; нужен Playwright и установленный Chromium:
CHROMIUM_PATH=/usr/bin/chromium node tests/snippets-browser.cjs
```

`SNIPPETS_URL` меняет адрес сервера. Runtime-зависимостей у приложения нет. Playwright нужен только для необязательного браузерного прогона, в `package.json` корневого Electron-приложения зависимости не добавлены. Снимки и тестовый экспорт записываются в `work/`.

Логические проверки: полнота каталога, миграция двух схем, нулевые/пустые метрики, бэкапы, ошибки хранилища, безопасные ссылки/ID, сохранение, дедупликация, замены и отмена, аналитика и очередь. Браузер: новая установка, редактирование после перезагрузки, Clipboard, этапы, публикация, метрики/графики, фильтры, генератор, тренды, план, мало сил, настройки, избранное/очередь, экспорт/импорт, offline, мигрированный профиль и отсутствие pageerror.
