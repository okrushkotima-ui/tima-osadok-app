Установить РИТМ на iPhone

Открой сайт в Safari → нажми «Поделиться» → «На экран Домой» → «Добавить». РИТМ будет запускаться без панели Safari.

Данные хранятся на этом устройстве в браузере. Пока нет синхронизации между iPhone и Windows. Не удаляй данные браузера без резервной копии.
