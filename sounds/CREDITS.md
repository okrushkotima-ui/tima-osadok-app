# Звуки РИТМ

Звуки в `sounds/*.wav` — Kenney Interface Sounds (2020), **CC0 1.0 Universal**.
Источник: https://kenney.nl/assets/interface-sounds
Библиотека WAV: https://github.com/Calinou/kenney-interface-sounds
Лицензия: https://creativecommons.org/publicdomain/zero/1.0/

Исходные имена:
- `success.wav` → `confirmation_001.wav`
- `impact.wav` → `drop_002.wav`
- `soft-no.wav` → `back_002.wav`
- `tap.wav` → `click_002.wav`
- `warm.wav` → `bong_001.wav`

Звуки воспроизводятся с умеренной громкостью и изменённой скоростью, без старых восьмибитных синтезаторов. Пользователь может выключить звук в приложении.
